# PromptLens

Idea se image tak. Turn a tiny idea into four ready-to-paste AI image prompts.

[Live demo](https://prompt-lens-magic.lovable.app)

## What it does

Idea daalo, model chuno, 4 concepts with copy-ready prompts milte hain.

## Features

- 4 distinct concepts per run
- GPT Image/Gemini/Midjourney/Flux adaptation
- Style presets
- History
- Surprise me

## Tech stack

React, TypeScript, Vite, Tailwind, shadcn/ui, built with Lovable.
